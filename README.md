# HACCP Suite

Веб-приложение управления пищевой безопасностью (ХАССП, ISO 22000:2018, ISO/TS 22002-1, BRCGS) для производителя джемов, варенья и конфитюров.
26 модулей в 5 группах; требования — [`docs/00-brief.md`](docs/00-brief.md), план — [`docs/01-plan.md`](docs/01-plan.md), статус приёмки — [`docs/03-acceptance.md`](docs/03-acceptance.md).

> Текущее состояние: **фаза 1** — оболочка (меню, верхняя панель, маршруты 26 модулей, модальные окна, уведомления, хлебные крошки), i18n ru/en/hy, тестовый контур. Модули — заглушки с пометкой «в разработке». Данные, вход и роли появятся на фазе 2.

## Запуск

Нужен **Node.js 22** или новее (Windows, macOS, Linux).

```bash
npm start
```

Команда сама установит зависимости (если их нет), соберёт клиент и запустит сервер: **http://localhost:3000**.
Порт меняется переменной `PORT` (`PORT=8080 npm start`).

Интернет нужен только при первой установке зависимостей. Во время работы приложение не обращается во внешнюю сеть: шрифты (включая армянские), иконки и библиотеки входят в сборку.

## Тесты

```bash
npx playwright install chromium   # один раз, нужен интернет
npm test
```

`npm test` выполняет: проверку типов → линтер → unit-тесты (Vitest) → e2e-тесты (Playwright, Chromium) → обновление [`docs/03-acceptance.md`](docs/03-acceptance.md).
Имя каждого теста начинается с кода критерия приёмки (`K1` … `K26`). Скриншоты проверок — в [`docs/evidence/`](docs/evidence/).

Во всех e2e-тестах действует общая проверка: любая ошибка в консоли браузера или запрос не на `localhost` валит тест.

## Языки

Русский, English, Հայերեն — переключатель в верхней панели, без перезагрузки страницы; выбор запоминается.
Словари: `shared/i18n/{ru,en,hy}.json`, ключи одинаковые (проверяется тестом). Термины — через [`docs/glossary.csv`](docs/glossary.csv).

> **hy — требует вычитки носителем.** Армянские тексты интерфейса и глоссария подготовлены исполнителем.

## Структура проекта

```
client/    интерфейс (React + Vite): оболочка, компоненты, i18n, стили
shared/    общий код клиента и сервера: реестр 26 модулей, словари, разбор чисел, время (Asia/Yerevan)
server/    локальный сервер (Fastify): API и раздача собранного клиента
scripts/   start.mjs (одна команда запуска), test.mjs, acceptance-report.mjs
tests/     unit/ (Vitest), e2e/ (Playwright), fixtures/
docs/      требования, план, нормативные ссылки, глоссарий, приёмка, скриншоты
```
